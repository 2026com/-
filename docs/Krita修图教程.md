# Krita 修图教程（零基础版 · 针对你的 PSD 定制）

> 你的拆层文件：`art/seethrough_output (1).psd`（1024×1024，15 个图层，全部已自动命名）
> 本教程只教 5 个操作，做完 4 个任务就收工。

---

## 一、第一次打开 Krita（10 分钟）

1. 打开 Krita → 菜单 **文件 → 打开** → 选 `art/seethrough_output (1).psd`
2. 如果界面是英文：**设置(Settings) → 切换界面语言(Switch Application Language) → 中文** → 重启 Krita
3. 认识四个区域：
   - 中间：画布（你的角色）
   - **右上：图层面板**（一列小缩略图，每个就是一个"部件"）——你 95% 的时间都在这里
   - 左侧竖条：工具栏（画笔/橡皮/吸管）
   - 顶部：菜单和笔刷大小滑条

## 二、只需要会的 5 个操作

| 操作 | 怎么做 |
| --- | --- |
| 看单个图层 | 图层面板点该层**前面的眼睛图标** = 显示/隐藏（其它层关掉就只剩这一层） |
| 缩放画布 | `Ctrl + 滚轮`（放大看边缘细节必备） |
| 移动画布 | 按住`空格`拖动，或选工具栏的"平移"工具（小手图标） |
| 橡皮擦 | 按 `E`（擦掉毛边白边）；再按 `B` 切回画笔；`Ctrl` 按住 = 吸管取色 |
| 笔刷大小 | 顶部工具栏滑条，修边用 3~10px 的小笔刷 |

⚠️ **三条保命规则**：
1. **永远不合并图层**（不要按 Ctrl+E，不要图层菜单里的"合并/拼合"）
2. **动手画之前，先在图层面板点选正确的图层**（高亮的那层才是你正在改的）
3. 改坏了就 `Ctrl+Z` 撤销（无限步）

## 四、四个任务（按顺序做）

### 任务 1：修边（预计 1~2 小时）
AI 拆层最容易留下：层与层之间的白边/毛边、没拆干净的碎块。
- 逐层检查：关掉其它层只看一层 → `Ctrl+滚轮` 放大到 200% → 绕边缘走一圈；
- 白边/突出的杂点：用小橡皮（3~8px）轻轻擦掉；
- 边缘缺了一块：按 `B` 画笔 → `Ctrl` 点旁边取色 → 涂补；
- ⚠️ 重点检查：front hair（前发最复杂）、eyelash（睫毛细碎）、face（脸部边缘）。

### 任务 2：新画一层「闭眼」（预计 30 分钟，眨眼必需）
现在的眼睛是"睁开的"（eyewhite+irides+eyelash 三层），没有闭眼状态就没法眨眼。
1. 在图层面板**新建图层**（面板底部"＋"图标），命名为 `eye-closed`，拖到 `eyelash` 层的**下面**；
2. 用画笔（深色，从 irides 取色偏深）在左右眼位置各画一条**向下弯的弧线**（闭眼的眼缝），线条外不要涂；
3. 自检：隐藏 eyewhite 和 irides 两层、只留 eye-closed + eyelash + face → 看起来像闭着眼就成功。

### 任务 3（可选）：新画一层「嘴内」（20 分钟，让张嘴更自然）
1. 新建图层 `mouth-inner`，拖到 `mouth` 层**下面**；
2. 在嘴的位置画一个小的深红色椭圆（张嘴时露出的口腔），平时被 mouth 层盖住看不见；
3. 张嘴动画 = mouth 层向上变形，露出下面的 mouth-inner。

### 任务 4：导出
- **文件 → 存储为** → 格式选 **PSD** → 存成 `art/整理后.psd`；
- ⚠️ 弹出的 PSD 兼容窗口保持默认（勾选保留图层）即可；
- **任何时候都别点"合并图像/拼合图层"**。

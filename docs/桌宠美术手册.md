## 线 2 · 拆层（一张图 → 23 层 PSD）—— 约 30 分钟，免费

**首选：ModelScope 在线演示**（see-through 官方为大陆用户维护，免费、国内直连、高分辨率）：

1. 打开 https://modelscope.cn/studios/ljsabc/See-Through
2. 注册/登录魔搭社区（手机号即可，免费）
3. 上传 `D:\小美\art\template1_transparent.png`（用这个英文文件名副本）
4. 点运行/生成，等几分钟（官方说每次约 2-3 分钟）
5. 下载输出的 **PSD 文件**，存到 `D:\小美\art\`

**备用**：HuggingFace Space https://huggingface.co/spaces/24yearsold/see-through-demo（每天免费 1-2 次，需注册 HF，分辨率略低）

**再备用（前面都失效时才用）**：AutoDL 租 RTX 4090（约 ¥2/小时）：
1. autodl.com 注册充值 ¥10 → 创建实例：算力市场选地区 → GPU 筛选 RTX 4090 → 镜像选「基础镜像」里的 PyTorch 2.x / CUDA 12.x → 创建并开机
2. 打开 JupyterLab，新建终端，逐条执行：

## 线 3 · Krita 修图整理 —— 业余 2~7 天

工具：[krita.org](https://krita.org) 免费下载（或先用 photopea.com 网页版预览 PSD）。

1. 打开拆层 PSD，逐层检查：隐藏其它层只看一层 → 修毛边/白边/残留（橡皮+邻近色涂抹）；
2. **只补两处**：被刘海遮住的额头+眉毛（吸附近旁皮肤色补）、被身体挡住的颈部线条；
3. 图层整理为规范命名、10~15 层：
   `头发前 / 眉毛L / 眉毛R / 眼(上下眼皮) / 嘴 / 脸 / 腮红 / 耳朵 / 脖子 / 身体 / 手臂L / 手臂R / 头发后 / 腿脚`
4. 自检：任一图层单独显示边缘完整；全显与原图一致；
5. 保留图层导出 PSD（**千万别合并图层**）。

**交付物**：`art/整理后.psd`

## 线 4 · Cubism 绑骨（阶段 D）—— 业余 2~4 周

1. Live2D 官网注册 → 下载 **Cubism Editor FREE 版**（免费可导出 moc3）；
2. 官方中文教程：live2d.com/zh-CHS/learn/ 的「入门」系列；
3. 导入线 3 的 PSD → 每层建网格（ArtMesh）；
4. 按里程碑做（**按下面清单建参数，名字一字不差**）：
   - 里程碑 1：眨眼（EyeLOpen/ROpen）+ 呼吸（Breath）+ 嘴开合（MouthOpenY/MouthForm）
   - 里程碑 2：头部转角（AngleX/Y/Z ±30）+ 眉毛（BrowLY/RY）+ 前发轻摆
   - 物理演算、大角度转头：**全部不做**
5. 导出 moc3 + 贴图文件夹 → 放 `D:\小美\art\model\`

**参数清单（照抄）**：

| 参数名 | 范围 |
|---|---|
| ParamAngleX / ParamAngleY / ParamAngleZ | ±30 |
| ParamEyeLOpen / ParamEyeROpen | 0~1 |
| ParamEyeLSmile / ParamEyeRSmile | 0~1 |
| ParamBrowLY / ParamBrowRY | -1~1 |
| ParamBrowLAngle / ParamBrowRAngle | -1~1 |
| ParamMouthOpenY | 0~1 |
| ParamMouthForm | -1~1 |
| ParamCheek | 0~1 |
| ParamBodyAngleX / Y / Z | ±10 |
| ParamBreath | 0~1 |

**不想学绑骨？** 线 3 完成后把 PSD + 本清单委托给淘宝/米画师的 Live2D 师傅（几百到三千元），效果相同。
